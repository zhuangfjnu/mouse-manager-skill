# mouse-manager-skill
Manage Mouse Colony is a practical workflow for maintaining laboratory mouse registration records and turning them into daily operational decisions.
# `manage-mouse-colony` 使用说明

## 用途

`manage-mouse-colony` 用于维护和查询小鼠个体登记信息，并基于本地数据生成日常管理提示与数据看板。它适用于新增个体、补充亲代信息、记录配对和产仔、查询基因型资源、计算分笼或繁殖时间，以及查看小鼠资源看板。

## 首次使用

在一段新对话中，首次触发该 skill 时，需要先提供小鼠个体登记在线文档地址，例如 KDocs 链接：

```text
https://www.kdocs.cn/l/...
```

该地址作为当前对话的源表参考。仅提供地址不会触发在线表格修改；只有明确要求编辑在线文档时，才会进行在线表格操作。





## 数据来源与看板

本地看板以当前对话中最新提供的 `.xlsx` 文件为导入来源，导入后转换为本地 CSV 快照。输入 `数据看板` 时，skill 会校验并导入该工作簿，然后打开或刷新本地看板：

```text
数据看板
```

看板地址为 `http://127.0.0.1:3176/`。看板中的日期和基因型筛选改变后，点击“刷新”会重新读取本地 CSV 快照并更新统计。

## 登记信息

个体登记表的核心字段如下：

| 字段 | 含义 |
| --- | --- |
| 目标号 | 小鼠耳号或唯一编号 |
| 基因型1 | 第一基因型及其纯合子/杂合子状态 |
| 出生日期 | 个体出生日期 |
| 性成熟日期 | 通常为出生日期后 56 天 |
| 性别 | 雌性或雄性 |
| 笼位坐标 | 当前饲养笼位 |
| 亲代1、亲代2 | 父母个体编号 |
| 产仔与配对记录 | 配对日期、状态、繁殖笼位、产仔日期、数量、预计分笼日期等历史信息 |

新增个体时，保留已有记录与繁殖历史，只追加新行或新的历史字段组；不会覆盖既有亲代、产仔或配对记录，除非明确要求纠正错误。

## 常用对话请求

| 请求示例 | 结果 |
| --- | --- |
| `增加一只小鼠 A2346 wnt1-cre 雌性 2026/01/21 7A15` | 追加个体并填写已提供信息 |
| `A2344 的亲代是 A89 和 A90` | 补充指定个体的亲代信息 |
| `列出 A2344 的信息` | 返回该小鼠的登记详情 |
| `目前有多少只 HR 小鼠` | 按基因型统计当前个体数 |
| `数据看板` | 使用当前对话最新的 XLSX 更新本地数据并打开看板 |
| `今日待办` 或 `今天有什么任务` | 在对话中输出当日管理事项 |

## 今日待办

输入 `今日待办` 或 `今天有什么任务` 时，结果按以下固定顺序输出：

1. 可配对资源：同一第一基因型下，已经性成熟的雌性与雄性个体。
2. 可剪尾：出生后 18 至 24 天的小鼠。
3. 单独一笼：当前笼位中仅有一只登记小鼠的笼位。
4. 需分笼：预计分笼日期已到或逾期，且繁殖状态未标记为完成、已分笼、已结束、终止或取消的记录。
5. 信息不全：目标号、基因型1、出生日期、性成熟日期、性别、笼位坐标、亲代1或亲代2存在缺失，或出生日期、性成熟日期不是有效日历日期的记录。

本地看板的“待办处理”区域使用同一套规则，显示每类的数量和个体明细。

## 日期规则

| 事项 | 计算规则 |
| --- | --- |
| 性成熟日期 | 出生日期 + 56 天 |
| 预计分笼日期 | 产仔日期 + 20 天 |
| 交配至产仔 | 配对日期 + 19 至 21 天 |
| 剪尾窗口 | 出生后 18 至 24 天 |

日期建议使用 `YYYY/M/D` 格式。日期值必须是有效日历日期，例如 `2026/2/30` 会被识别为无效。

## 目标基因型繁殖估算

询问目标基因型后代所需时间时，skill 会从登记表读取亲本已记录的基因型，不假设未登记的等位基因存在。对于需要两代获得的目标，计算会依次给出：

1. 亲本配对后的首代出生时间。
2. 首代断奶与基因分型时间。
3. 首代达到性成熟并可再次配对的时间。
4. 第二代出生时间。
5. 第二代断奶、基因分型和确认目标个体的最早实际时间。

例如，杂合子与杂合子交配时，单一 flox 位点获得纯合子的理论概率为 25%。Cre 的遗传概率取决于登记的 Cre 合子状态；未知时会明确标注为估算。

## 数据边界

- 在线表格仅在明确要求时修改，并在修改后核对表头与值是否对齐。
- `数据看板` 不会修改在线表格，只会用当前对话提供的 XLSX 更新本地快照。
- `今日待办` 只输出结果，不修改 XLSX、CSV 或在线表格。
- 当缺少有效 XLSX 时，保留已有本地快照，不以空数据覆盖。
